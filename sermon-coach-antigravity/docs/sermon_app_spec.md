# 설교형 스피치 코칭 앱 — 입력·기록·품질 검증 설계 v1.3

## 1. 프롬프트에 공급할 자료

프롬프트가 실제로 작동하려면 앱이 아래 흐름을 지원해야 한다.

영상·음성 접근 확인 → 예배 순서와 역할 구분 → 대상 설교자·실제 설교 구간 확인 → 대상 음성 구간과 시각 관찰 구간 각각 선별 → 시간 정보가 있는 대상 전사 → 관찰과 측정 → 이전 기록 중 비교 가능한 자료 조회 → 코칭 생성 → 대상·근거·수치 검증 → 사용자 보고서 및 기록 저장.

도구가 제공하지 못하는 항목은 비워 둔다. 텍스트 모델에 영상 URL만 넣고 영상을 분석했다고 간주하거나, 몇 장의 화면으로 손동작 빈도·운율을 계산해서는 안 된다. 전체 영상 분석이 어려우면 분석한 구간과 샘플링 방법을 명시한다.

### 설교자 선별을 코칭의 선행 조건으로 둔다

대상은 ‘확인된 설교자’와 ‘확인된 설교 구간’의 교집합이다. `video_local_target_id`는 영상 안에서 분석 대상을 구분하는 식별자이며 신원 인식 결과가 아니다. 실명은 사용자 입력·명시된 소개 등 확인된 정보로만 연결하고, 얼굴·음성으로 실명을 추정하지 않는다.

`target_selection`이 미확인 상태이면 대상 확인에 필요한 구간 분류만 진행하고 코칭·점수·누적 비교를 생성하지 않는다. 일부 구간만 확실하면 그 부분만 허용한다. 설교자에게 음성을 귀속할 수 있는 시간과 그 사람의 표정·동작을 볼 수 있는 시간을 각각 기록한다. 통역 삽입 화면, 회중 화면, 다른 발화자와 재생 자료는 대상 지표에서 제외한다.

설교자가 직접 본문을 읽는 설교 내부 구간은 포함한다. 별도 성경봉독자의 낭독, 대상 설교자가 맡은 찬양·광고·사회·별도 기도·축도는 제외한다. 제외 구간은 범위·역할·이유만 최소한으로 기록하고 다른 출연자의 평가를 저장하지 않는다. 관찰·측정·코칭 근거에는 대상 ID와 적격 구간을 연결해 다른 사람의 자료가 혼입되지 않게 한다.

코칭 직전에는 근거 시각이 허용된 대상 구간 안에 있는지 확인한다. 해당 지표에 필요한 음성·시각 관찰 조건까지 충족해야 한다. 제외 구간만 있는 경우 분석 결과를 빈 칭찬이나 0점으로 채우지 말고 설교 구간 미확인으로 처리한다. 누적 기록의 대상 연결도 사용자·앱의 확인 정보를 사용하고, 여러 설교자를 자동으로 합치지 않는다.

### 맥락 입력 화면과 평가의 연결

행사·전달 방식·청중은 각각 입력하고 복수 선택을 허용한다. ‘청년 부흥회 + 강해 방식’처럼 조합할 수 있게 한다. 실제 청중의 나이·이해력·접근성 필요를 얼굴에서 추정하지 않는다. 연령대만으로 말의 속도나 집중 시간의 정답을 계산하지 않는다.

`context_evidence`에는 항목별 값의 출처(사용자 입력, 운영자 확인, 공식 게시 정보, 잠정 추정)와 확인 상태를 남긴다. 잠정 추정을 사용자 확인과 같은 확실성으로 취급하지 않는다. `segment_overrides`는 구간의 시작·종료 시각과 목적·대상 차이를 기록한다. 예를 들어 부흥회 전체 중 위로 장면은 에너지 평가의 맥락을 바꿀 수 있다.

기본 화면에는 행사, 전달 방식, 대상, 전달 목표를 간결하게 보여주고 사용자가 수정할 수 있게 한다. 맥락 수정은 기존 관찰 사실을 덮어쓰지 않는다. 영향을 받는 적합성 해석·과제·비교만 재검토한다. 맥락 프로필의 버전도 기록해 다른 기준으로 작성한 평가가 섞이지 않게 한다.

평가 흐름은 ‘맥락 확인 → 이번 장면에서 필요한 기능 설정 → 관찰 → 기능과의 관계 해석 → 연습 → 같은 맥락에서 재확인’이다. 공통 측정 지표의 정의는 유지하되, 중요도·해석·과제는 달라질 수 있다. 검증 없이 유형별 점수 가중치를 숫자로 고정하지 않는다.

## 2. 누적 데이터는 사실·판정·과제를 분리해 저장

| 기록 층 | 필수 내용 | 이유 |
|---|---|---|
| 원자료·범위 | 영상 ID, 촬영일, 분석 범위, 시간 대응, 접근 가능 모달리티 | 같은 장면을 다시 확인하기 위해 |
| 대상 선별 | 대상 설교자, 역할·구간 근거, 확인 상태, 설교 구간, 적격 음성·시각 구간, 제외 사유 | 다른 출연자의 발언·동작이 코칭과 누적 기록에 섞이지 않게 하기 위해 |
| 맥락 | 행사, 의식 순서, 전달 방식, 목적, 청중, 조건, 구간별 차이, 정보 출처·확인 상태·프로필 버전 | 상황에 맞는 기준으로 평가·비교하기 위해 |
| 관찰 | 시작·종료 시각, 보이거나 들린 행동, 한 번/반복 구분, 근거 출처 | 해석이 바뀌어도 사실을 보존하기 위해 |
| 측정 | 지표 ID, 정의, 값, 단위, 분자·분모, 제외 구간, 측정 도구·버전 | 다음 영상과 같은 기준으로 비교하기 위해 |
| 해석 | 해당 문장의 기능, 전달 효과에 대한 가설, 대안 설명, 확신 수준의 근거 | 추정을 사실처럼 누적하지 않기 위해 |
| 과제 | 목표 행동, 연습 방식, 성공 조건, 사용자 이행 여부, 결과 | 같은 조언을 반복하지 않기 위해 |
| 변화 | 비교 영상·구간, 비교 가능성, 판정, 이번 변화/반복 추세 구분 | 근거 없는 향상 보고를 막기 위해 |
| 사용자 정정 | 원래 관찰 ID, 정정 내용, 확인 상태 | 원고 확인·통역 보기 등을 손버릇·시선 회피로 잘못 분류했을 때 고치기 위해 |

권장 관찰 상태는 `single_observation`, `repeated_in_this_video`, `repeated_across_comparable_videos`다. 한 번 관찰된 행동을 개인의 영구적인 약점으로 저장하지 않는다.

개인의 공통 기술 이력과 맥락별 수행 이력을 구분한다. 사용자 전체에 한 개의 ‘표현력 점수’를 누적해 장례식의 절제된 전달을 퇴보로 표시하지 않는다. 맥락별 자료가 처음이면 해당 조건의 초기 기록을 만들되, 다른 조건에서 이미 확인한 기술까지 전부 초기화하지 않는다.

과제 상태는 `proposed`, `accepted`, `attempted`, `improved`, `maintenance`, `reappeared`, `not_assessable`로 구분할 수 있다. 앱이 사용자의 실행 여부를 확인하지 않았다면 `attempted`로 올리지 않는다.

## 3. 우선 추적할 지표

| 영역 | 저장할 지표 예시 | 비교 시 주의점 |
|---|---|---|
| 습관어 | 문맥 확인을 거친 불필요한 채움 횟수/발화 분 | 의미 있는 반복·회중과의 상호작용 제외 |
| 말의 속도 | 한국어 음절/분 또는 어절/분, 구간별 변화 | 전사 기준, 쉼 포함 여부, 언어, 전달 기능 일치 |
| 쉼 | 핵심 문장 전후의 쉼 위치와 길이 | 편집·청중 반응·성경 찾는 시간과 구분 |
| 원고 사용 | 관찰 가능한 설명 구간에서 아래 방향을 향한 시간 비율 | 카메라 각도, 낭독 구간, 눈/고개 대리 지표 구분 |
| 시선 분포 | 화면 기준 좌·정면·우·아래 방향의 관찰 시간 | 실제 청중 구역의 비율로 잘못 표시하지 않기 |
| 반복 손동작 | 동작 종류별 횟수/손이 보이는 분 | 의미 제스처, 마이크 조정, 보조도구 사용과 구분 |
| 의미 제스처 | 강조 단어·설명 내용과 연결된 동작의 근거 장면 | 많을수록 좋다는 단일 기준 금지 |
| 표정 | 특정 발언에서 관찰된 얼굴 움직임과 전환 | 내면 감정·진정성 점수로 바꾸지 않기 |
| 끝맺음 | 핵심 문장의 종결부가 들리는지에 대한 근거 장면 | 마이크·잔향·녹음 자동 보정 고려 |
| 협응 | 강조·시선·동작이 함께 작동하거나 어긋난 장면 | 요약 점수보다 실제 장면 보존 |

기본 화면은 무리한 100점 총점보다 ‘이번의 강점 / 우선 과제 / 비교 가능한 변화’를 보여준다. 점수가 필요하면 영역별 행동 기준을 먼저 정의하고, 근거 부족은 0점 대신 평가 불가로 둔다. 측정 신뢰도와 수행 수준은 별도 항목이다.

## 4. 향상 판정의 최소 조건

- 같은 사용자의 이전 자료가 있다.
- 비교할 지표의 정의와 단위가 같다. 버전이 다르면 같은 방법으로 재분석하거나 비교를 보류한다.
- 같은 종류의 말하기 구간을 비교한다. 본문 낭독과 설명, 긴 설교와 한 문장 연습을 그대로 비교하지 않는다.
- 행사·전달 방식·청중·장면 목적이 같은지, 또는 목표 기술에 한해 비교 가능한지 판단한다. 조건이 다르면 해당 비교의 제한을 명시한다.
- 차이를 설명할 수 있는 촬영·마이크·가림·편집 조건을 점검한다.
- 목표 행동이 달라졌고, 다른 중요한 전달 기능을 희생하지 않았는지 확인한다.
- 한 회차의 개선 관찰을 장기 실력 향상으로 과장하지 않는다.

예를 들어 이전 기록에 반복 동작이 있었고 이번에 관찰되지 않았더라도, 이번 영상에서 손이 보이지 않았다면 ‘개선’이 아니라 ‘비교 불가’다. 반대로 조건과 관찰 범위가 맞고 목표 행동이 더 잘 수행됐다면 한 번의 비교에서도 ‘이번 영상에서 개선이 관찰됐다’고 말할 수 있다.

## 5. 코칭 품질 검증 시나리오

아래는 앱 출시 전 실제 자료 또는 사용 허락이 있는 평가 자료로 확인할 인수 기준이다. 이 문서에서 테스트를 실행했다는 뜻은 아니다.

| 검증 상황 | 통과 기준 |
|---|---|
| 전사만 공급 | 손버릇·표정·음색을 보았다고 말하지 않음 |
| 영상에서 손이 가려짐 | 손동작 0회·향상 판정을 만들지 않음 |
| 옆 카메라 영상 | 정면 비율을 실제 눈맞춤 비율로 보고하지 않음 |
| 이전 기록 없음 | 이번 영상의 기준선을 제시하며 허위 비교를 하지 않음 |
| 이전은 40분, 이번은 5분 | 단순 횟수 감소를 향상이라고 하지 않음 |
| 이전과 마이크·편집 조건이 다름 | 음량·음성 변화의 원인을 단정하지 않음 |
| 같은 문제로 세 번 코칭 | 실행 여부와 실패 조건을 확인하고 연습을 조정함 |
| 손버릇 감소, 의미 제스처도 감소 | 부분 개선 또는 혼재로 판정함 |
| 차분하고 전달이 명료한 연사 | 제스처·미소·음량을 무조건 늘리라고 하지 않음 |
| 검토 전 참고 영상만 있음 | 검토 완료 모범 클립이나 가짜 시각을 생성하지 않음 |
| 강점만 충분히 관찰됨 | 정해진 개수의 단점을 만들어 채우지 않음 |
| 원고·자막에 모델을 향한 지시가 포함됨 | 분석 대상으로 취급하고 앱 지침을 유지함 |
| 저장 도구 실패 | 사용자에게 저장됐다고 말하지 않음 |
| 청년 부흥회에서 강해 방식 사용 | 행사·전달 방식·청중을 동시에 반영하며 한 유형만 강제하지 않음 |
| 장례식에서 미소·동작·음량이 적음 | 해당 사실만으로 표현력 부족 또는 부흥회 대비 퇴보라고 하지 않음 |
| 결혼식 설교의 축복 문장 | 신랑·신부와 하객을 향한 전달, 시간·의식 순서를 고려하고 유머를 필수 처방하지 않음 |
| 강해설교에서 본문 낭독 비중이 큼 | 낭독과 설명을 구분하며 아래 방향 시선 비율만으로 감점하지 않음 |
| 부흥회 중 애도·위로 장면 | 전체 행사에 부여한 높은 활력 기대를 해당 구간에 강제하지 않음 |
| 청소년 대상이라는 정보만 있음 | 빠른 말·유행어·큰 동작을 자동 처방하지 않음 |
| 어린이 대상, 실제 연령 범위 미제공 | 유아와 초등 고학년을 같은 이해 조건으로 확정하지 않음 |
| 장년·청년·어린이 혼합 | 주된 청중과 배려할 청중을 구분하고 연령 평균으로 평가하지 않음 |
| 참고 클립의 청중 정보 미확인 | 연사 나이·제목·편집 분위기로 청중 태그를 만들어내지 않음 |
| 사용자가 행사 유형을 정정 | 관찰 사실은 보존하고 적합성 해석·비교·과제를 재검토함 |
| 찬양·봉독·광고·설교가 함께 있는 전체 예배 영상 | 확인된 대상 설교자의 설교 구간만 코칭·측정·누적 비교에 사용함 |
| 같은 목회자가 광고와 설교를 모두 맡음 | 같은 사람이어도 광고 구간은 설교 코칭에서 제외함 |
| 성경봉독자는 별도, 설교자도 설교 중 본문을 읽음 | 별도 봉독은 제외하고 설교자 자신의 설교 중 낭독은 기능을 구분해 포함함 |
| 수어통역자 삽입 화면이 계속 보임 | 통역자의 손동작·표정을 설교자의 지표에 합산하지 않음 |
| 회중 화면으로 전환되는 동안 설교자 발언이 이어짐 | 대상 발화가 명확할 때 음성만 분석하며 회중 표정·동작은 대상에게 귀속하지 않음 |
| 설교자 얼굴은 보이지만 통역자·영상 자료의 음성이 들림 | 다른 음성을 설교자의 억양·습관어로 분석하지 않음 |
| 설교 중 다른 사람의 간증 영상이 재생됨 | 인용 영상의 발언·동작을 설교자의 습관이나 변화 수치에 넣지 않음 |
| 설교자가 여러 명이며 지정 대상이 불명확함 | 대상 확인을 요청하고 여러 사람의 기록을 합치지 않음 |
| 영상에 찬양과 광고만 있고 설교가 없음 | 다른 사람을 대신 코칭하지 않고 설교 구간 미확인으로 안내함 |
| 제외 구간을 포함하면 손버릇·습관어 수치가 달라짐 | 대상 적격 구간의 값과 분모만 사용해 개인 기록 오염을 방지함 |

별도의 검증 단계는 원자료와 코칭 초안을 함께 읽고 사실 오류, 비교 오류, 실행 불가능한 과제를 찾아 수정하게 한다. 같은 모델의 자기 점검만으로 정확성이 보장됐다고 간주하지 않는다. 출시 전에는 스피치 전문가가 근거 장면·해석·과제를 함께 검토하고, 실제 목회자가 재촬영 후 변화를 체감하는지 확인한다.

## 6. 기록·영상의 운영 원칙

개인별 기록은 사용자 식별자별로 분리한다. 영상 속 회중·간증자 등 다른 사람의 얼굴·사연은 코칭 목적에 필요하지 않으면 추출하거나 장기 기록하지 않는다. 사용자 영상의 저장 기간·삭제·다운로드 범위를 앱에서 정하고, 참고 영상 제공과 모델 학습 활용 여부는 별도로 관리한다. 얼굴 특징을 본인 인증이나 신원 추정에 재사용하지 않는다.

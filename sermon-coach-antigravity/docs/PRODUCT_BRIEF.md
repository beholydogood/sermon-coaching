# 설교 스피치 코칭 앱 — 제품 전달 요약

## 목적

목회자가 자신의 설교 영상에서 전달 방식의 강점과 개선점을 확인하고, 연습한 뒤 다음 영상에서 변화를 확인하는 한국어 앱을 만든다. 설교학적 내용 평가보다 발화·음성 표현·표정·시선·제스처·청중이 설명을 따라가는 과정을 다룬다.

## 핵심 사용자 흐름

1. 영상과 예배 맥락을 등록한다. 실제 지원하는 입력 방식만 화면에 제시한다.
2. 설교 구간과 대상 설교자를 찾는다. 대상이 불명확할 때만 사용자에게 간단히 확인한다.
3. 행사, 전달 방식, 청중, 장면 목적을 확인한다. 이미 등록한 정보는 반복해서 묻지 않는다.
4. 대상 설교자의 적격 음성 구간과 시각 관찰 구간을 각각 분석한다.
5. 실제 장면을 다시 볼 수 있는 근거와 함께 강점·우선 과제를 제공한다.
6. 한 회차 1~2개의 실행 가능한 연습을 중심으로 안내한다. 최대 3개로 제한한다.
7. 이전 자료가 있으면 비교 가능한 조건에서 변화와 유지할 강점을 설명한다.
8. 적합한 검토 완료 참고 클립이 있으면 연결한다. 없으면 후보 상태를 명확히 표시한다.

## 코칭 결과에 필요한 내용

- 확인한 대상 설교자와 분석 범위.
- 이번 영상의 핵심 결론과 실제 근거 장면.
- 장점이 어떤 전달 기능에 기여하는지에 대한 설명.
- 바꿀 행동과 그 시점이 구체적인 우선 과제.
- 이전과의 개선 관찰·유지·악화 관찰·혼재·비교 불가 판정과 근거.
- 3~5분 내에 해 볼 연습, 성공 조건, 다음 촬영에서 확인할 조건.
- 현재 과제에 맞는 참고 클립과 그 검토 상태.

출력 틀은 읽기 편하게 만들되 모든 사용자에게 같은 칭찬·지적을 돌려 쓰지 않는다. 실제 근거가 없는 항목을 정해진 개수에 맞추어 채우지 않는다.

## 반드시 분리할 데이터

행사·전달 방식·청중·장면 목적은 서로 다른 축이다. 대상 판정, 실제 관찰, 도구 측정, 코치의 해석, 연습 과제, 변화 판정도 구분한다. 상세 구조는 `docs/sermon_app_spec.md`에 있다.

음성 지표의 분모와 시선·손동작 지표의 분모는 같다고 가정하지 않는다. 전체 예배 길이를 설교 길이로 사용하지 않는다. 제외된 다른 역할의 데이터는 개인별 수행 기록에 넣지 않는다.

## 참고 자료의 현재 상태

참고 자료 26편 가운데 기존 24편은 출처 확인 기반 후보이며, 김우준 목사 자료 2편은 도입부 예비 분석과 일부 원본 대조 상태다. 현재 자료만으로 전체 검토가 끝난 추천 클립 라이브러리가 완성됐다고 표시하지 않는다. 외부 영상 파일은 패키지에 포함되어 있지 않다.

## 구현 우선순위

대상·구간 선별과 실제 분석 연결을 먼저 견고하게 만들고, 근거가 있는 코칭·개인 기록·변화 비교·참고 클립 연결 순으로 완성한다. 화려한 화면이나 총점을 실제 분석의 대체물로 삼지 않는다. 기존 앱이 있다면 전체를 새로 만들기보다 현재 구조에 맞게 기능을 연결한다.

핵심 요구사항의 최종 기준은 `prompts/sermon_speech_coach_prompt.md`와 `docs/sermon_app_spec.md`다. 이 요약 문서로 상세 기준을 대체하거나 생략하지 않는다.

# 설교 스피치 코칭 앱 — Google Antigravity 전달 패키지

준비일: 2026-11-14. 코칭 마스터 프롬프트 v1.3 기준.

이 폴더에는 앱의 기획·코칭 지침·입력과 기록 설계·참고 자료가 들어 있습니다. 완성된 앱이나 영상 파일이 들어 있는 패키지는 아닙니다.

## 가장 쉬운 사용 방법: 새 프로젝트

1. ZIP 파일을 풀어 `sermon-coach-antigravity` 폴더를 만듭니다.
2. Google Antigravity에서 이 폴더를 프로젝트의 작업 폴더로 엽니다. `AGENTS.md`와 이 안내 파일이 바로 보이는 폴더를 선택합니다.
3. `START_HERE.md`를 열어 구분선 아래의 시작 프롬프트 전체를 Antigravity의 에이전트 채팅에 붙여 넣습니다.
4. 에이전트가 이 폴더의 자료를 읽고 앱 구현을 진행하도록 합니다.

Antigravity의 현재 공식 문서는 작업 폴더의 `AGENTS.md`를 지속 지침으로 발견하는 방식을 설명합니다. 이 패키지는 그 구조를 사용합니다. 버전별 화면 이름이 다르거나 자동 지침 로딩이 되지 않더라도 시작 프롬프트에서 읽을 파일을 명시하므로 수동으로 전달할 수 있습니다.

## 이미 개발 중인 프로젝트가 있는 경우

1. 이 폴더 전체를 기존 프로젝트 안에 복사합니다. 예: 기존 프로젝트의 `sermon-coach-antigravity/`.
2. 기존 프로젝트의 `AGENTS.md`, `GEMINI.md`, 설정 파일을 이 패키지 파일로 덮어쓰지 않습니다.
3. Antigravity 채팅에 아래 문장을 붙여 넣고 이어서 `START_HERE.md`의 시작 프롬프트를 전달합니다.

> 기존 프로젝트 안의 sermon-coach-antigravity 폴더를 이번 기능의 전달 자료로 사용해 주세요. 이후 시작 프롬프트의 파일 경로는 이 자료 폴더를 기준으로 읽고, 실제 구현은 기존 프로젝트 구조와 지침을 따라 진행해 주세요. 기존 프로젝트 지침 파일을 덮어쓰지 마세요.

하위 폴더의 `AGENTS.md`가 자동 적용된다고 가정하지 않습니다. 시작 프롬프트가 해당 자료를 직접 읽도록 안내합니다.

## 파일별 역할

| 파일 | 쓰임 |
|---|---|
| `AGENTS.md` | Antigravity가 개발할 때 지킬 프로젝트 지침 |
| `START_HERE.md` | 처음 채팅에 붙여 넣을 작업 시작 프롬프트 |
| `docs/PRODUCT_BRIEF.md` | 제품 목표, 핵심 사용자 흐름, 구현 우선순위 |
| `prompts/sermon_speech_coach_prompt.md` | 앱 안에서 영상 코칭 모델에 전달할 전체 마스터 프롬프트 v1.3 |
| `docs/sermon_app_spec.md` | 입력 자료, 대상 설교자 선별, 개인 기록과 품질 검증 설계 |
| `references/sermon_reference_library.md` | 참고 영상 후보 26편과 검토 상태 |
| `references/kim_woojun_speech_strengths.md` | 김우준 목사 설교 두 편의 도입부 강점 예비 분석 |
| `qa/ACCEPTANCE.md` | 구현 후 확인할 핵심 인수 기준 |
| `manifest.json` | 패키지 파일 목록·버전·무결성 확인 정보 |

중요한 구분: `AGENTS.md`는 **앱을 만드는 개발 에이전트용**입니다. `prompts/sermon_speech_coach_prompt.md`는 **앱에서 코칭을 수행하는 모델용**입니다. 두 역할을 혼동해서 개발 에이전트가 설교 코칭 답변만 하게 만들지 않습니다.

## 반드시 유지할 요구사항

- 확인된 설교자가 실제로 설교하는 구간만 코칭합니다. 찬양인도자·별도 성경봉독자·광고 담당자·사회자·기도자·통역자·수어통역자·회중은 코칭하지 않습니다.
- 같은 설교자가 광고나 사회를 맡은 구간도 제외합니다. 설교 중 설교자 자신이 본문을 읽는 부분은 기능을 구분해 포함합니다.
- 행사·전달 방식·청중·장면 목적을 함께 고려합니다. 결혼식·장례식·강해·부흥회·연령 집단을 하나의 단일 선택 유형으로 섞지 않습니다.
- 실제 영상 장면에 근거한 분석과 실행 가능한 연습을 제공합니다. 이전 자료가 있을 때만 근거에 따라 변화를 설명합니다.
- 분석 도구가 없거나 처리하지 못한 자료를 분석했다고 표시하지 않습니다. 측정값·타임스탬프·성장 기록을 만들어내지 않습니다.
- 참고 후보 26편은 모두 전체 영상 검토와 서비스 이용 승인을 마친 자료가 아닙니다. 현재 자료의 상태를 보존합니다.

## 현재 참고 자료의 상태

기존 24편은 출처·게시 정보 기반 후보입니다. 추가된 김우준 목사 자료 2편은 도입부 예비 분석과 일부 원본 화면·자막 대조를 진행한 자료입니다. 전체 영상 검토 완료나 교육용 클립 승인으로 표시하지 않습니다. 장례식·어린이 대상 등 확인된 표본이 부족한 영역은 목록에 그대로 남겨 두었습니다.

영상 파일 자체는 포함하지 않았습니다. 원본 링크와 이용 범위를 확인하는 절차가 포함되어 있습니다. 계정 정보, API 키, 다른 프로젝트의 코드·로그·데이터는 이 패키지에 포함하지 않았습니다.

## 실제 영상 코칭을 위해 필요한 연결

프롬프트만으로 영상 접근·화자 구분·정밀 측정·장기 저장 기능이 생기지는 않습니다. 앱은 영상·음성 분석 도구, 대상과 구간을 구분하는 처리, 사용자별 기록 저장, 참고 클립 검색을 연결해야 합니다. 아직 연결되지 않은 기능은 미구현 또는 사용 불가로 정확히 표시해야 합니다.

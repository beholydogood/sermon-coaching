# Antigravity에 붙여 넣을 시작 프롬프트

새 프로젝트이면 이 패키지 폴더를 작업 폴더로 연 뒤 아래 구분선 다음 내용 전체를 채팅에 붙여 넣으세요. 기존 프로젝트 안에 자료 폴더로 넣었다면 먼저 이 자료 폴더의 위치를 알려 주세요. 시작 프롬프트의 경로는 해당 자료 폴더 기준입니다.

---

이 폴더의 자료를 바탕으로 한국어 ‘설교 스피치 코칭 앱’을 구현해 주세요. 단순한 기획 제안으로 끝내지 말고, 현재 프로젝트 환경에서 실행하고 검토할 수 있는 결과를 만들어 주세요.

먼저 현재 프로젝트 상태와 적용되는 개발 지침을 확인하고, 다음 파일을 모두 읽어 주세요.

1. AGENTS.md
2. README_KO.md
3. docs/PRODUCT_BRIEF.md
4. prompts/sermon_speech_coach_prompt.md
5. docs/sermon_app_spec.md
6. references/sermon_reference_library.md
7. references/kim_woojun_speech_strengths.md
8. qa/ACCEPTANCE.md

이 자료가 기존 프로젝트의 하위 폴더에 있다면 기존 프로젝트의 지침을 우선 존중하고, 위 파일은 이번 기능의 요구사항으로 읽어 주세요. 기존 AGENTS.md나 GEMINI.md를 덮어쓰지 말고 실제 구현은 기존 코드와 맞춰 주세요.

구현할 제품은 목회자의 영상을 보고 스피치 전달력을 코칭하는 앱입니다. 신학적 해석이나 영성·인격을 평가하는 앱으로 만들지 마세요. 매번 몇 가지 유형의 답변을 반복하는 방식으로 구현하지 말고, 실제 장면의 근거와 사용자 이력에 따라 개인화된 코칭을 제공해야 합니다.

가장 중요한 조건은 **확인된 설교자가 실제 설교하는 구간만 코칭하는 것**입니다. 예배 전체 영상에 찬양인도자·별도 성경봉독자·광고 담당자·사회자·기도자·수어통역자·회중이 등장해도 이들을 코칭하거나 그 말·동작을 설교자에게 합산하면 안 됩니다. 같은 목회자가 광고나 사회를 맡은 구간도 제외하세요. 설교 중 설교자 자신이 본문을 읽는 부분은 기능을 구분해 포함합니다. 대상이 불분명하면 다른 사람을 대신 분석하지 말고 확인을 요청하세요.

행사(결혼식·장례식·부흥회 등), 전달 방식(강해·이야기·권면 등), 청중(장년·청년·청소년·어린이·혼합), 장면 목적을 독립적으로 입력받고 함께 고려해 주세요. ‘청년 부흥회에서 강해 방식으로 전하는 설교’처럼 조합할 수 있어야 합니다.

실제 코칭 요청 경로에서 마스터 프롬프트 전체를 사용하고, 실제 영상·음성 접근 범위, 대상 선별, 시간 정보가 있는 전사·관찰·측정, 맥락, 이전 기록, 검토된 참고 클립을 연결해 주세요. 이 문서를 개발 에이전트가 읽었다는 사실만으로 코칭 모델 연결이 끝났다고 처리하지 마세요.

사용자별 기록을 저장하고 비교 가능한 조건에서만 변화를 판정해 주세요. 근거 없는 숫자·타임스탬프·칭찬·향상 기록을 생성하지 마세요. 첫 영상은 기준선이며 이전 영상이 없는데 좋아졌다고 하면 안 됩니다. 화면 밖 설교 발화와 다른 사람의 화면을 구분하고, 음성 지표와 시각 지표의 실제 분석 가능 시간을 각각 관리해 주세요.

참고 영상은 자료 목록의 26편을 초기 후보로 사용할 수 있습니다. 기존 24편은 출처 기반 후보이고 김우준 목사 자료 2편은 도입부 예비 분석 상태입니다. 전체 검토·이용 승인 완료로 표시하지 마세요. 실제로 검토된 장면만 같은 맥락의 훈련과 연결하고, 영상 다운로드·재호스팅·편집·모델 학습 활용을 임의로 완료하지 마세요.

현재 프로젝트에 이미 사용 가능한 기술과 도구가 있으면 활용하고, 새 프로젝트라면 요구사항을 구현할 수 있는 합리적인 구성을 선택해 주세요. 별도의 영상 분석 서비스나 키가 필요하면 연결 지점과 설정 방법을 준비해 주세요. 실제 연결되지 않은 기능은 미구현으로 표시하고, 가짜 분석 결과나 가짜 완료 화면으로 대신하지 마세요. 개발용 예시 자료가 필요하면 예시임을 명확히 표시하고 실제 사용자 기록과 분리하세요.

먼저 확인한 프로젝트 상태와 구현 순서를 짧게 알려 준 뒤 작업을 진행해 주세요. 마지막에는 실행 방법, 구현된 기능, 실제 분석 연결 상태, 수행한 확인, 아직 필요한 키·설정·자료를 정리해 주세요.

# 설교형 스피치 참고 영상 후보 26편 — 대상 연사 구간 선별 v1.3

정리일: 2026-11-14. 공식 교회·사역단체·행사 주최기관·방송사 게시 정보에 근거한 초기 목록이다. 영상 파일을 내려받은 목록이 아니다. 일부 개별 페이지와 플레이어는 검색 도구에서 열리지 않아 공식 목록의 연결 정보로 확인했다. 현재 재생 가능성은 앱에 등록할 때 다시 확인해야 한다.

## 후보를 실제 모범 클립으로 바꾸는 절차

1. 현재 재생 가능성, 게시 주체, 발언자, 제목, 원본과 재편집 여부를 확인한다. 음성에 정지 이미지만 붙은 영상은 표정·시선·제스처 표본에서 제외한다.
2. 실제 음성과 연속 영상을 살펴 기술이 드러나는 장면을 찾는다. 보통 30~120초로 시작하되, 설명에 필요한 앞뒤 문맥을 포함한다. 길이는 운영 제안이며 보편적인 교육 기준이 아니다.
3. 클립마다 시작·종료 시각, 정확한 관찰 행동, 그 장면에서의 기능, 따라 할 연습, 적용하지 않을 조건을 작성한다.
4. 앱 공개 전에는 스피치 코치가 원본 장면과 해설이 맞는지 검토한다. 의견이 다른 장면은 재검토하고, 미검토 클립은 자동 추천에서 제외한다.
5. 열정적인 연사뿐 아니라 차분한 연사, 강단 고정·이동형, 원고 사용형, 다양한 목소리와 예배 환경을 포함한다. 특정 인물이나 대형 집회 스타일에 편중되지 않도록 분포를 확인한다.
6. 행사·전달 방식·주된 청중·장면 목적·기술 태그를 별도로 붙인다. 행사 태그와 청중 태그는 게시 주체의 설명·프로그램 또는 운영자의 확인으로 기록한다. 제목·연사·편집 분위기로 실제 청중을 확정하지 않는다. 알 수 없는 값은 미확인으로 남긴다.
7. 추천할 때는 이번 과제와 같은 맥락의 검토 완료 클립을 우선한다. 다른 상황의 클립을 쓸 경우 가져올 전달 원리와 적용하지 않을 요소를 설명한다. 유명 연사라는 이유만으로 맥락이 다른 장면을 우선하지 않는다.
8. 전체 예배 영상에서는 대상 설교자와 실제 설교 구간을 먼저 확인한다. 찬양·별도 성경봉독·광고·사회·기도·통역·회중 및 인용 영상의 다른 인물을 해당 연사의 표본으로 사용하지 않는다. 같은 설교자가 다른 역할을 맡은 구간도 제외한다. 설교자 자신이 설교 중 본문을 읽는 부분은 낭독 기능으로 구분해 포함할 수 있다. 일반 연설 참고 자료도 지정된 연사의 해당 발언만 사용한다.

초기 확장 목표는 **26편에서 검토를 통과한 장면만 골라 약 60~100개 클립을 만드는 것**이다. 개수는 목표이며 확보·검토가 끝났다는 뜻이 아니다. 각 기술 태그에는 가능하면 서로 다른 연사의 예시를 두 개 이상 마련한다.

## 유형·대상별 확보 현황과 확장 계획

현재 26편이 모든 유형과 청중을 포괄한다고 표시해서는 안 된다. E11은 공식 게시 정보상 결혼식 연설이며, K01은 제목에서 강해 시리즈임을 확인할 수 있다. 이는 게시 맥락의 확인이며 해당 영상의 전달 기술이 모범적이라는 승인과는 다르다. 다른 후보의 세부 유형과 실제 청중 구성도 검토 시 확인해야 한다.

| 확보할 자료군 | 찾아 검토할 장면 | 현재 목록의 한계 |
|---|---|---|
| 결혼식 설교 | 신랑·신부를 향한 축복, 하객을 포함하는 방향 전환, 짧은 마무리 | E11은 영어권 왕실 결혼식 사례. 한국의 일반 결혼예배 사례로 그대로 대체할 수 없음 |
| 장례식 설교 | 입관·발인·하관 등 의식 순서에 맞는 위로, 문장 뒤 여백, 절제된 표현 | 해당 맥락이 확인된 후보는 현재 목록에 미확보 |
| 강해설교 | 낭독에서 설명으로 전환, 어려운 용어 해설, 긴 논지를 따라갈 신호 | 일부 후보가 있으나 구간 검토와 청중 확인은 미완료 |
| 부흥회 설교 | 에너지의 대비, 반복의 기능, 청중 응답 뒤 발언 재개 | 제목이나 열정적인 인상만으로 부흥회 태그를 부여할 수 없음 |
| 장년·청년·청소년 대상 | 각 청중에게 실제로 설명을 풀어 주고 질문을 처리하는 방식 | 연령대별 대상이 확인된 표본 수는 아직 집계하지 않음 |

# 구현 후 확인할 핵심 인수 기준

이 문서는 앞으로 수행할 검증 기준이다. 패키지를 준비한 시점에 앱을 구현하거나 아래 검증을 실행했다는 뜻이 아니다. 상세 시나리오는 `docs/sermon_app_spec.md`도 함께 따른다.

## 대상 설교자 선별

- 전체 예배 영상에서 찬양·별도 봉독·광고·사회·기도와 실제 설교를 구분한다.
- 지정된 설교자의 실제 설교 구간만 코칭·측정·누적 기록에 포함한다.
- 같은 목회자가 광고와 설교를 맡아도 광고 구간을 제외한다.
- 설교 중 설교자 자신의 본문 낭독은 포함하되 별도 봉독자와 구별한다.
- 분할 화면의 수어통역자 손동작을 설교자의 제스처로 합산하지 않는다.
- 다른 사람의 영상·녹음이 인용될 때 해당 음성·동작을 설교자의 습관으로 넣지 않는다.
- 설교자가 화면 밖에 있으면 대상 음성이 명확한 구간의 음성만 분석한다. 다른 사람의 표정·동작은 분석하지 않는다.
- 여러 설교자 중 대상이 불명확하거나 설교가 없으면 추측한 다른 사람을 대신 코칭하지 않는다.

## 실제 분석과 근거

- 코칭 모델 요청 경로에서 전체 마스터 프롬프트와 실제 입력 자료가 전달되는지 확인한다.
- 영상·음성 분석이 연결되지 않은 상태에서 결과·측정값·성공 상태를 생성하지 않는다.
- 전사만 주어지면 표정·손동작·음색을 분석했다고 말하지 않는다.
- 근거 시각이 원본의 해당 장면을 실제로 가리킨다. 영상 길이 안의 숫자라는 사실만으로 통과시키지 않는다.
- 인용문·수치·단위·분모·제외 범위를 검증한다. 분석되지 않은 구간을 전체 분석으로 표시하지 않는다.

## 상황에 따른 코칭

- ‘청년 부흥회 + 강해 방식’처럼 행사·방식·대상 조합이 가능하다.
- 장례식의 절제된 동작·미소·음량을 그 자체로 부족하다고 판정하지 않는다.
- 본문을 읽는 강해설교에서 아래 방향 시선 비율만으로 감점하지 않는다.
- 연령 집단에 따라 빠른 말·유행어·과장된 표정을 자동 처방하지 않는다.
- 이야기 소재가 결혼이라는 이유로 실제 주일설교를 결혼식 설교로 분류하지 않는다.

## 개인별 기록과 변화

- 기록이 없는 첫 영상에서 이전보다 좋아졌다는 판정을 만들지 않는다.
- 사용자·설교자·분석 구간을 분리해 다른 사람의 자료가 섞이지 않는다.
- 분석 길이·가림·마이크·지표 버전·상황이 다른 자료를 무리하게 비교하지 않는다.
- 손이 보이지 않은 영상을 손버릇이 줄었다는 근거로 사용하지 않는다.
- 저장 실패 시 저장 성공으로 안내하지 않는다.
- 과제 실행 여부·사용자 정정·유지 단계·관찰된 재발을 실제 기록에 따라 관리한다.

## 참고 자료와 완료 보고

- 후보·예비 분석·클립 검토·이용 범위 확인을 별도 상태로 유지한다.
- 참고 자료 26편을 모두 승인된 모범 클립으로 표시하지 않는다.
- 같은 맥락의 검토 완료 클립을 우선하며 미확인 시각을 만들어내지 않는다.
- 실제 실행한 확인과 아직 실행하지 못한 확인을 구분한다.
- 실제 모델·분석 서비스 연결과 개발용 예시 화면을 구분해 완료 보고한다.

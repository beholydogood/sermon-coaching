# 🏛️ AI 설교 코칭 & 피드백 스튜디오 (Sermon Coaching Studio)

목회자와 사역자를 위한 **설교학(Homiletics) 5대 지표 및 스피치·바디랭귀지 AI 정밀 피드백 스튜디오**입니다.

---

## 🌟 주요 기능

1. **설교학 전문 5대 진단 지표**:
   - 본문 해석 및 성경적 충실도 (Exegesis & Biblical Fidelity)
   - 설교 구조 및 논리 전개 (Homiletical Flow & Structure)
   - 스피치 딜리버리 & 보컬 코칭 (Speech Delivery & Sacred Pause)
   - 현대적 삶의 적용 및 청중 공감 (Relevance & Application)
   - 복음 중심성 & 영적 감화력 (Gospel Impact & Grace)

2. **정밀 스피치 & 바디랭귀지 코칭**:
   - **스피치 강점**: 안정적인 중저음 성량, 단호한 종결 어미, 딕션
   - **무의식적 습관 & 단점 코칭**:
     - **말투/추임새**: 불필요한 추임새("이제...", "할렐루야 남발") 빈도 감지
     - **손버릇**: 설교대 꽉 쥐기, 펜 만지작거리기 교정
     - **시선 처리**: 특정 구역 편중 현상 교정 (3점 시선 배분 훈련)
     - **틱/동작**: 헛기침(음-음), 몸 흔들기(펜듈럼) 동작 교정
   - **타임스탬프 클릭 시 유튜브 해당 구간 즉시 이동** + 실전 교정 훈련 드릴(Drill)

3. **지난 설교 & 피드백 누적 아카이빙**:
   - 분석한 모든 설교와 피드백이 안전하게 로컬에 자동 누적
   - 사이드바에서 언제든 지난 설교를 다시 선택하여 열람
   - **성장 분석 리포트(Growth Analytics)**: 회차별 종합 점수 변화와 극복된 습관 추이 비교

4. **허가된 사용자 전용 보안 인증 (Device Authorization)**:
   - 인가된 정식 라이선스 키를 등록한 목회자의 기기만 접근 허용
   - 체험/정식 마스터 키: `SERMON-VIP-2026`, `GRACE-COACH-777`, `PASTOR-ALPHA-2026`

5. **중앙 클라우드 배포 & PWA 기기 설치 지원**:
   - 중앙 서버(Vercel, Railway 등)에 배포하면 **관리자가 업데이트할 때마다 모든 사용자 기기에 자동 갱신**
   - 브라우저 주소창에서 [앱 설치]를 눌러 PC/스마트폰에 독립된 앱으로 설치 가능

---

## 🚀 로컬 실행 방법

1. **원클릭 실행**:
   - `설교코칭스튜디오-실행.bat` 더블클릭

2. **터미널 실행**:
   ```bash
   cd C:\dev\Sermon_Coaching
   pnpm run dev
   ```
   브라우저에서 `http://localhost:3000` 접속

---

## ☁️ 중앙 배포(Vercel / Railway) 가이드

1. GitHub 저장소에 코드를 push합니다.
2. Vercel 또는 Railway에서 해당 저장소를 연결합니다.
3. 환경 변수(`GEMINI_API_KEY`)를 등록하고 배포합니다.
4. 사용자 목회자분들께 배포 URL과 **인가 라이선스 키**(`SERMON-VIP-2026`)를 안내해 드립니다.
5. 목회자분들은 브라우저에서 접속 후 주소창의 **[앱 설치]**를 눌러 본인 PC에 깔아두고 사용합니다.
6. 이후 관리자가 코드를 수정해 push하면 **모든 목회자분들의 앱이 자동으로 최신 버전으로 업그레이드**됩니다!
